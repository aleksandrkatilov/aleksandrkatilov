PauseCut 2.1

Less silence. More story.

Quickly edit talking-head and vlog footage: merge your clips, automatically speed up or remove pauses, fine-tune the timeline and turn a long video into vertical Shorts.

A complete editing workflow

Merge. Find pauses. Preview. Refine.

01

Bring your footage together

Drag in videos one by one, in a batch or as a whole folder. Arrange the clips, then edit them as a single timeline.

  • Reorder by dragging or with the up/down buttons, or sort clips by name.
  • Merge clips into one timeline and export them as one file.
  • Automatically normalizes mixed resolutions, rotation, variable frame rates, 10-bit and HDR footage from phones, Meta glasses and other cameras.

Inputs: MP4, MOV, MKV, AVI, M4V, MTS, WEBM.

02

Let pauses do less of the talking

Speed up quiet sections from ×2 to ×30, or remove them entirely. Keep control over how close each edit gets to speech.

  • Adjust the silence threshold, margin around speech and minimum pause length.
  • Start with the Storage Unit or Bike Vlog preset.
  • The Before → After duration estimate updates in about a second as settings change.
03

Watch the edit before rendering

Play all source clips back to back, then switch to Preview result to see how the finished edit will flow.

  • The player skips pauses and cut sections in Preview result mode.
  • See the matching time in the final video alongside the source position.
  • Footage above 1080p gets a lightweight background proxy for playback. Rendering still uses the original files.
04

See what stays, speeds up or goes

A color-coded audio waveform makes speech and pauses easy to spot, with clip boundaries and file names visible.

  • Speech, accelerated sections and cuts each have their own color.
  • A dashed line shows the silence threshold.
  • Zoom with Ctrl+wheel, scroll with the wheel, or fit the entire timeline.

YouTube Shorts

One long video. A batch of Shorts.

  • Select a range and press H, or import a clip list from CSV. Export the list to CSV whenever you need it.
  • Review start, end and duration, and edit each title and hook text directly in the table.
  • A warning appears when a clip exceeds three minutes.
  • Export at 1080×1920 with a blurred background or a center crop.
  • Optionally remove pauses inside each Short and burn in subtitles from an SRT file.
  • Clip lists are remembered for each set of source videos. Render the entire batch into a NAME_SHORTS folder.

Separate transcription tool

Add speech recognition when needed.

Run «Распознать речь.bat» (Transcribe speech) to create subs.srt with short 3–5 word captions and a transcript.json file.

  • Uses Whisper large-v3-turbo on a compatible NVIDIA GPU with 4+ GB VRAM; the medium model runs on the CPU as a slower fallback.
  • Requires Python 3.10+. The first model download needs an internet connection and approximately 1–2 GB.
Render and export

Finish with a ready-to-share MP4.

  • Optional NVIDIA NVENC hardware encoding can be enabled with a checkbox.
  • Follow the progress bar, stop a render, or open the output folder when it finishes.
  • Settings are remembered between launches.
  • Errors appear in a dialog, with a crash log saved locally.
