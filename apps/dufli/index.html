Start on the same network

Install, then pair.

  1. Run Windows Setup. It includes the required runtime and the Android APK.
  2. Install the APK on your phone. You can download it here or scan the installer's APK download QR while connected to the same local network.
  3. For pairing, scan the separate QR in the Windows Pairing tab from Add computer on Android, then approve the phone on the PC.
  4. Choose the Windows receive folder and the default PC on Android. You are ready to share files.

Local, with verification.

After installation, file transfers work without internet, accounts, a cloud relay or analytics. File exchange uses certificate-pinned HTTPS and device-specific authorization.

Received files are checked against their size and SHA-256 before completion. They open only when you choose to open them.

A few useful details.

The phone cannot reach the PC

Check the same local network, the selected PC network adapter and guest Wi-Fi client isolation. Allow on private network starts a separate firewall setup with Windows confirmation; the rules are restricted to the app, local subnet and Private network profile.

Download QR and pairing QR are different

The installer download link lasts 15 minutes and serves only the bundled public APK over local HTTP. Keep its window open while downloading. The main app's pairing code lasts two minutes and authorizes a device for HTTPS file exchange.

Receiving, updates and compatibility

Keep Android open to accept files from the PC. Before updating Windows, choose Exit in the tray; closing its window keeps the receiver running. Install the Android APK over the existing app to retain its pairings and history.

Tested on Windows 11 x64 and an Android 17 emulator. APK downloading was also confirmed on a physical phone. Windows 10, Android 10–12 and full physical-phone pairing/transfer checks require further validation.
